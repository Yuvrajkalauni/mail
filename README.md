# Mail — Single-Page Email Client

A single-page email client built with **JavaScript, HTML, CSS, and Django**, developed as part of **CS50's Web Programming with Python and JavaScript**.

The application allows users to send, receive, view, archive, unarchive, and reply to emails through a dynamic single-page interface. JavaScript communicates with the Django backend using REST API requests to update and retrieve email data without requiring full page reloads.

## Features

*  **Inbox** — View received emails with sender, subject, timestamp, and read/unread status.
*  **Send Mail** — Compose and send emails with recipients, subject, and message body.
*  **Sent Mailbox** — View emails sent by the current user.
*  **Archive & Unarchive** — Archive received emails and restore them to the inbox when needed.
*  **View Email** — View the complete sender, recipients, subject, timestamp, and body of an email.
*  **Read Status** — Automatically mark emails as read when they are opened.
*  **Reply** — Reply to existing emails with automatically populated recipients, subjects, and quoted original messages.
*  **Single-Page Navigation** — Switch between Compose, Inbox, Sent, Archive, and individual email views dynamically.
*  **Asynchronous API Requests** — Use JavaScript Fetch API to communicate with the Django backend.
*  **Responsive Interface** — Designed to provide a usable email experience across different screen sizes.

* **Backend:** Python, Django
